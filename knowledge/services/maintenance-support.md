# Maintenance & Support

## Overview

AVENIQ delivers comprehensive Maintenance & Support services designed to ensure that business software, SaaS products, web applications, and cloud infrastructure remain secure, operational, and aligned with evolving organizational needs. The service provides structured post-launch technical management—including 24/7 uptime monitoring, proactive security dependency patching, bug resolution, database backup verification, performance optimization, and SLA-backed developer support.

Software applications require ongoing care after initial deployment. Third-party npm dependencies evolve, browser engines update, security vulnerabilities emerge, and database stores expand. AVENIQ provides dedicated engineering support that prevents technical debt accumulation, shields applications from security exploits, and guarantees high availability.

Whether supporting custom enterprise software, multi-tenant SaaS products, or mobile API backends, AVENIQ offers clear Service Level Agreements (SLAs) that provide business leaders with complete technical peace of mind.

## Business Value

Securing ongoing professional software maintenance provides vital financial and operational protection:

1. **Prevention of Costly System Downtime**: Proactive server and code monitoring resolves potential issues before they escalate into revenue-impacting system outages.
2. **Protection Against Security Exploits**: Timely patching of underlying framework dependencies and operating system libraries shields applications against hacker exploits and data breaches.
3. **Preservation of Long-Term Software Asset Value**: Regular maintenance prevents software decay, preserving the financial and technical value of custom software investments over time.
4. **Rapid Technical Assistance**: Defined Service Level Agreements (SLAs) ensure that dedicated developers respond to urgent issues immediately.
5. **Continuous Feature Progression**: Monthly developer hour allocations allow businesses to continuously roll out minor feature improvements and UI enhancements without signing new project contracts.

## Frequently Asked Questions

### What is included in AVENIQ's maintenance service?
AVENIQ maintenance covers 24/7 uptime monitoring, proactive security dependency patching, bug fixes, database backup management, performance optimization, and an allocation of monthly developer hours for feature updates.

### What is a Service Level Agreement (SLA)?
A Service Level Agreement (SLA) defines structured response times for technical support requests. For example, a critical production outage SLA commits an engineering response within 1 to 2 hours.

### Can AVENIQ maintain software that was developed by another company?
Yes. AVENIQ conducts an initial onboarding audit to review the existing codebase, server setup, and documentation before taking over ongoing maintenance and support.

### How do we submit support requests or report bugs?
Clients can submit support requests via a dedicated ticketing portal, direct Slack/WhatsApp channels, or email. Urgent critical incidents trigger immediate high-priority alerts to on-call engineers.

### What happens to unused monthly developer hours?
Depending on contract terms, unused monthly developer hours can roll over for up to 30 days or be applied toward larger planned feature development sprints.

### How are database backups verified?
AVENIQ configures automated daily database backups and periodically performs test restoration runs to ensure that backup files are uncorrupted and ready for emergency recovery.

### How often are security patches applied?
Critical security patches are applied immediately upon discovery, while routine framework and dependency updates are deployed during monthly scheduled maintenance windows.

### Who owns the code updates and bug fixes completed during maintenance?
The client retains 100% full ownership of all source code updates, bug fixes, custom features, and technical documentation produced during maintenance.
